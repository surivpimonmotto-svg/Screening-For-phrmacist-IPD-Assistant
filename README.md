# IPD Screening Assistant — คู่มือสำหรับผู้ร่วมพัฒนา

โปรแกรมช่วยเภสัชกรคัดกรองคำสั่งใช้ยาผู้ป่วยใน (IPD) ก่อนคีย์จ่าย ห้องยา IPD รพ.มหาสารคาม
เวอร์ชันปัจจุบัน: **v0.9.7** (ดูประวัติใน `CHANGELOG.md`)

> ⚠️ **ห้ามใส่ชื่อ-สกุล หรือ HN/AN ผู้ป่วย** ลงในโปรแกรม ไฟล์ log หรือภาพที่ส่งให้ AI
> ข้อมูลผู้ป่วยถูกประมวลผลในเบราว์เซอร์เท่านั้น ไม่ส่งออกไปที่ใด

---

## 1. ไฟล์ในชุดนี้

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | **โปรแกรมที่ใช้งานจริง** (รวมทุกอย่างในไฟล์เดียว) — ไฟล์นี้คือที่ GitHub Pages แสดง |
| `src/` | ต้นฉบับแยกส่วน (ใช้เมื่อแก้ไข แล้วรวมด้วย `build.py`) |
| `build.py` | รวม `src/` → `index.html` |
| `CHANGELOG.md` | บันทึกการแก้ไขทุกเวอร์ชัน (**ต้องเขียนเพิ่มทุกครั้งที่แก้**) |

### ส่วนต่าง ๆ ใน `src/`

| ไฟล์ | เนื้อหา | แก้เมื่อ |
|---|---|---|
| `kb.js` | **ฐานกฎยา**: ขนาดยาตามไต (bands ตาม CrCl), HD/CAPD/CRRT, เด็ก mg/kg, TB, HAD, DUE, ยาซ้ำซ้อน, Warfarin DI, ATB lock, Metformin, KCl | ขนาดยา/จุดตัด/แหล่งอ้างอิงเปลี่ยน — **แก้บ่อยที่สุด** |
| `cross.js` | ตารางแพ้ยาข้ามกลุ่ม (beta-lactam side chain, NSAIDs, AEDs, sulfonamide) | เพิ่มกลุ่มยาแพ้ข้าม |
| `master.js` | บัญชียา รพ. (รหัสยา + ชื่อ) | บัญชียาเปลี่ยน |
| `engine.js` | ตัวอ่านคำสั่งยา (parse) และตรรกะการตรวจ | อ่านคำสั่งผิด / ตรรกะเตือนผิด |
| `ui.js` | หน้าจอแท็บต่าง ๆ + เครื่องคำนวณ (HAD, ยาน้ำ, Dextrose, Opioid, Vanco/Colistin, Timeline, Warfarin) + **เลขเวอร์ชัน** (บรรทัด `ต้นแบบ v…`) | แก้หน้าจอ/สูตรคำนวณ |
| `lab.js` | ผล Lab (อ่านจาก HIS, ANC, corrected Ca), ตรวจสูตร ARV, สูตรยาเคมีบำบัด (CHEMO_REG จากชีท CMT) | เพิ่มสูตรเคมีบำบัด / กฎ ARV / ชื่อ Lab |
| `policy.js` | มาตรการ/กฎเพิ่มเติม: ยาพ่น Asthma/COPD, Fentanyl patch, anticoagulant, ADR ยาวัณโรค, opioid, antipsychotics | เพิ่มมาตรการ/กฎใหม่ |
| `dtl.js` | แท็บแผนภาพ Timeline ยา (วาด SVG แบ่งหน้า, พิมพ์ PDF, บันทึกไฟล์) | แก้หน้าตาแผนภาพ/หัวกระดาษ |
| `tools.js` | นับเม็ดยาถึงวันนัด (ARV) · แท็บคู่มือย่อ (REF) | เพิ่มหัวข้อคู่มือย่อ |
| `adr.js` | แท็บ ADR ทั้งหมด (timeline, Naranjo, WHO-UMC, RegiSCAR, SCORTEN, ALDEN, PEN-FAST, ฟอร์ม MKH-FR-PHA-048, พิมพ์ A4) | แก้ส่วน ADR |
| `shell.html` | โครงหน้าเว็บ + CSS (สี, ตัวอักษร, print) | แก้หน้าตา |

### ตัวอย่างกฎยาใน `kb.js`
```js
B(lo, hi, 'ข้อความแสดง', dose_สูงสุดต่อครั้ง, dose_สูงสุดต่อวัน)   // ใช้เมื่อ lo ≤ CrCl < hi
```
เช่น `B(0,10,'250-500 mg q24h',500,500)` = CrCl < 10 ให้ไม่เกิน 500 mg/ครั้ง และ 500 mg/วัน

ผลการตรวจมี 4 ระดับ: **ต้อง consult** (flag) · **ทบทวน** (warn) · **OK** · **ไม่มีกฎ** (info)

## 2. วิธีแก้ไข (แบบง่าย — ใช้ Claude)

1. ดาวน์โหลด **ไฟล์ล่าสุด** จาก GitHub เสมอ (ไม่ใช้ไฟล์เก่าในเครื่อง)
   - ถ้าแก้เล็กน้อย: แนบ `index.html` ไฟล์เดียวก็พอ
   - ถ้าแก้มาก: แนบ zip ทั้งชุด (หรือไฟล์ใน `src/` ที่เกี่ยวข้อง + README นี้)
2. บอก Claude ให้ชัด พร้อม **ที่มา** เช่น
   > "Meropenem CrCl 10–25 ตามคู่มือไต DIS 2568 ต้องเป็น 500 mg q12h แต่โปรแกรมขึ้นทบทวน — แก้ให้ตรง และเปลี่ยนเวอร์ชันเป็น v0.6.6"
   แนบภาพคู่มือ/ใบ DUE ได้ (**ปิดชื่อ/HN ก่อน**)
3. ทดสอบไฟล์ใหม่กับเคสจริงอย่างน้อย 2–3 เคส รวมเคสที่ควร OK ด้วย
4. **ให้เภสัชกรอีกคนตรวจ** ถ้าเป็นการแก้กฎขนาดยา
5. อัปโหลดขึ้น GitHub (ข้อ 3) และเขียน `CHANGELOG.md`

## 3. วิธีอัปโหลดขึ้น GitHub

1. เข้า repo → **Add file → Upload files**
2. ลากไฟล์ที่แก้ (`index.html` และไฟล์ใน `src/` ถ้ามี, `CHANGELOG.md`) ลงไป
3. ช่อง *Commit changes* เขียนสั้น ๆ เช่น `v0.6.6 แก้ Meropenem CrCl 10-25`
4. กด **Commit changes** → รอ 1–2 นาที → เปิดหน้าเว็บแล้วกด **Ctrl+F5** ตรวจว่าเลขเวอร์ชันมุมบนเปลี่ยน

ถ้าอัปแล้วพัง: เปิดไฟล์ใน GitHub → **History** → เลือกเวอร์ชันก่อนหน้า → ดาวน์โหลดแล้วอัปทับ

## 4. ถ้าแก้ใน `src/` เอง
```
python3 build.py
```
แล้วอัปทั้ง `index.html` และไฟล์ `src/` ที่แก้ — **ต้องอัปทั้งคู่** ไม่อย่างนั้นต้นฉบับกับโปรแกรมจริงจะไม่ตรงกัน

## 5. กติกาทีม

1. **เลขเวอร์ชัน**: แก้กฎ/บั๊ก → เพิ่มหลักสุดท้าย (v0.6.5 → v0.6.6) · เพิ่มแท็บ/ฟีเจอร์ใหญ่ → เพิ่มหลักกลาง (v0.7.0)
2. **ก่อนแก้ แจ้งในกลุ่ม LINE** ว่ากำลังแก้ส่วนไหน กันแก้ทับกัน
3. **กฎยาทุกข้อต้องมีที่มา** (คู่มือ DIS / ใบ DUE / ป้ายห้องยา / ประกาศ คกก.) เขียนไว้ใน CHANGELOG
4. ข้อที่ยังไม่ได้ทวนสอบโดย DIS ให้คงเครื่องหมาย ⚑
5. ผลทดลองใช้บันทึกในแบบบันทึก (Google Sheet) — ช่อง "ผลจริง" = เตือนผิด / อ่านคำสั่งผิด / ควรเตือนแต่ไม่เตือน คือรายการที่ต้องนำมาแก้

## 6. เรื่องที่ค้างอยู่ (ณ v0.6.5)
- Dopamine ช่วง/สูงสุด และ Adrenaline สูงสุด: โปรแกรม vs ชีทห้องยา (dopamine 2–15, max 40; adrenaline max 2) — รอยืนยัน
- ขนาดยาทารกแรกเกิด (เช่น Meropenem neonate) — ยังไม่มีกฎ ต้องใช้แนวทาง DIS/กุมาร
- Thai algorithm (ADR) — รอแบบฟอร์ม รพ.
- เตือนเมื่อ CrCl ใกล้จุดตัดตาราง / ตรวจ loading dose ของยา DUE — เสนอไว้ ยังไม่ทำ
- โมดูลยาเคมีบำบัด — ได้ไฟล์ CMT แล้ว ยังไม่ทำ
- ทุกรายการ ⚑ รอ DIS ทวนสอบ
